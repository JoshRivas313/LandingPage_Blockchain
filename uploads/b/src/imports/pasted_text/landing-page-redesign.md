Rediseña y mejora la landing page del evento tecnológico tomando como base el diseño actual, pero elevando considerablemente su calidad visual y experiencia de usuario.

El objetivo es crear una landing **moderna, tecnológica, profesional y dinámica**, con estética de evento organizado por una comunidad universitaria/tech. Debe sentirse como una landing real de un evento tecnológico importante, no como una plantilla genérica.

### DIRECCIÓN VISUAL

Utiliza una estética **Light Tech / Modern Tech**.

NO quiero una landing completamente blanca y plana.

Utiliza como base:

* Fondo general: `#F5F7FA`
* Secciones y tarjetas: `#FFFFFF`
* Azul principal: `#2563EB`
* Azul oscuro: `#0F172A`
* Azul secundario/acento: `#60A5FA`
* Texto principal: `#1E293B`
* Texto secundario: `#64748B`
* Bordes: `#E2E8F0`

La mayor parte de la interfaz debe mantenerse clara, pero combinar fondos gris-azulados muy suaves, tarjetas blancas y acentos azules para generar profundidad.

Evitar:

* Una interfaz completamente blanca.
* Exceso de gradientes.
* Fondos oscuros en toda la página.
* Efectos neon exagerados.
* Demasiadas sombras.
* Diseño sobrecargado.

Usar sombras muy suaves, bordes sutiles, buen espacio en blanco, esquinas ligeramente redondeadas y una jerarquía tipográfica clara.

# 1. HERO

Crear un Hero visualmente potente.

Debe comunicar inmediatamente:

* Nombre del evento.
* Fecha.
* Lugar.
* Temática tecnológica.
* CTA principal para registrarse.

Agregar elementos gráficos tecnológicos muy sutiles, como patrones, líneas, puntos o formas geométricas, pero sin saturar el diseño.

El Hero debe mantener un fondo claro y utilizar `#2563EB` y `#0F172A` como colores de contraste.

### ORGANIZADO POR DSC UTP

Dentro del Hero o inmediatamente debajo de él, mostrar claramente:

**Organizado por DSC UTP**

Utilizar exactamente **el logo/imagen de DSC UTP proporcionado anteriormente**.

El logo debe tener buena presencia visual y no verse como un elemento añadido de último momento.

---

# 2. INFORMACIÓN DEL EVENTO

Crear una sección breve que explique el propósito del evento.

Utilizar tarjetas o bloques visuales para mostrar información como:

* Fecha
* Hora
* Lugar
* Modalidad
* Networking
* Charlas técnicas

Mantener esta sección limpia y escaneable.

---

# 3. COMUNIDADES ALIADAS

Crear una sección:

**Comunidades Aliadas**

Mostrar los logos de las comunidades aliadas en un **slider/carrusel automático**.

El carrusel debe:

* Avanzar automáticamente.
* Tener una transición suave.
* Ser continuo y elegante.
* Permitir navegación manual.
* Adaptarse correctamente a mobile.
* Mantener todos los logos dentro de un área visual uniforme.

No deformar los logos.

---

# 4. PONENTES

IMPORTANTE:

La sección de **Ponentes debe aparecer ANTES del Cronograma**.

Título:

**Ponentes**

Subtítulo:

**Conoce a quienes compartirán su experiencia y conocimiento durante el evento.**

Como existen varios ponentes, NO mostrarlos todos en una cuadrícula enorme.

Crear un **slider/carrusel automático de ponentes**.

### Comportamiento del slider

* Cambio automático aproximadamente cada **1 segundo**.
* Transición suave y rápida.
* Navegación manual mediante flechas.
* Indicadores de posición.
* Responsive.
* En mobile debe seguir siendo cómodo de visualizar.

Cada tarjeta de ponente debe mostrar:

* Fotografía.
* Nombre completo.
* Cargo.
* Empresa/comunidad.
* Información profesional relevante.

Diseñar las tarjetas con fondo blanco, borde sutil, sombra ligera y pequeños acentos azules.

El slider debe sentirse dinámico, pero profesional.

# 5. CRONOGRAMA DEL EVENTO

Esta sección debe aparecer **después de Ponentes**.

Título:

**Cronograma del Evento**

Subtítulo:

**Un día completo de aprendizaje y networking**

IMPORTANTE:

Mostrar **ÚNICAMENTE el cronograma del AUDITORIO**.

NO mostrar:

* Salón A0307.
* Salón A0308.
* Tabs para cambiar de salón.
* Actividades de otros ambientes.

El Auditorio debe ser presentado directamente como el espacio principal.

Utilizar una línea de tiempo vertical o tarjetas conectadas visualmente.

Cada actividad debe mostrar claramente:

**Hora**

**Nombre de la actividad**

**Ponente**

**Cargo**

Utilizar pequeños indicadores azules para las horas y una línea visual que conecte todas las actividades.

# EXPERIENCIA DE USUARIO

Priorizar:

* Responsive design.
* Mobile first.
* Excelente legibilidad.
* Navegación sencilla.
* Jerarquía visual clara.
* Animaciones suaves.
* Microinteracciones.
* Buen contraste.
* Carga visual equilibrada.

La página debe sentirse **premium, tecnológica y profesional**, pero sin caer en un diseño excesivamente futurista.

La prioridad visual debe ser:

**Contenido → Personas → Cronograma → Registro**

No sobrecargar la interfaz con efectos que distraigan del contenido.

Mantener consistencia entre botones, tarjetas, tipografías, iconografía, espaciados y componentes.

IMPORTANTE: conservar los elementos existentes que ya funcionan correctamente y aplicar estas mejoras sin eliminar funcionalidades importantes del diseño actual.
